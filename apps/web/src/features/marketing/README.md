# Marketing feature

Reusable components for the public product pages.

The navigation uses `public/logo/soFlott_arrow_nav.png`, a tightly cropped
variant of the supplied `soFlott_arrow.png`, so its wordmark remains legible.
The header uses a 96px-wide logo and a compact single-row layout. Below the
desktop breakpoint, an accessible disclosure menu contains page links and
booking controls without increasing the collapsed header height.
