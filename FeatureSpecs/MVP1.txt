1. EXECUTIVE SUMMARY & BUSINESS MODEL
--------------------------------------------------------------------------------
- Company Name: soFlott UG (haftungsbeschränkt) / soFlottOS
- Business Model: General B2B Express & Direct Courier Service (Direktfahrt / Eiltransport)
- Core Value Proposition: Ultra-fast, point-to-point B2B delivery for local enterprises 
  (auto workshops, legal firms, tech parts, etc.) backed by custom software tracking, 
  digital signatures, and automated invoicing.
- Monetization & Payment (v1 MVP): 
  * Orders are placed online.
  * System instantly calculates pricing (Base + Distance in KM) + 19% German VAT (MwSt).
  * Invoices are automatically generated (PDF) upon order placement.
  * Payment handled via Bank Transfer (Überweisung) or manual PayPal settlement.

--------------------------------------------------------------------------------
2. USER ROLES & ACCESS CONTROL (JWT + RBAC)
--------------------------------------------------------------------------------
- Client (B2B):
  * Can register and log in.
  * Can book ad-hoc delivery orders.
  * Can provide specific instructions / extra notes per order (e.g., "Ask for warehouse manager Hans").
  * Can view order history, download invoices, and check delivery status.

- Driver:
  * Can log in and toggle availability status (Online / Offline / Blocked).
  * Automatically blocked/busy when assigned to an active delivery job.
  * Automatically released back to 'Online' status upon submitting Proof of Delivery (PoD).
  * Can view assigned delivery details, pickup/dropoff addresses, and route instructions.

- Admin:
  * Full operational oversight.
  * Manages client accounts and manual driver assignments.
  * Monitors revenue, order statuses, and invoice payment states.

--------------------------------------------------------------------------------
3. DATABASE SCHEMA SPECIFICATIONS (MySQL 8.0+)
--------------------------------------------------------------------------------
- Users Table: Id, Email, PasswordHash, FullName, Role (Admin, Client, Driver), CreatedAt
- Clients Table: Id, UserId (FK), CompanyName, ContactPerson, Email, Phone, Street, City, PostalCode, TaxIdNumber (USt-IdNr.)
- Orders Table: Id, ClientId (FK), AssignedDriverId (FK), CargoCategory, WeightKg, PickupAddress, PickupLat, PickupLng, DropoffAddress, DropoffLat, DropoffLng, DistanceKm, EstimatedPriceNet, VatAmount (19%), TotalPriceGross, SpecialInstructions (TEXT), Status (Pending, Assigned, InTransit, Delivered, Cancelled), CreatedAt
- ProofOfDeliveries Table: Id, OrderId (FK), RecipientName, SignatureDataUrl (LONGTEXT Base64), GpsLatitude, GpsLongitude, DeliveredAt
- Invoices Table: Id, InvoiceNumber, ClientId (FK), NetTotal, VatTotal, GrossTotal, Status (Draft, Sent, Paid, Overdue), IssuedAt, DueDate

--------------------------------------------------------------------------------
4. BACKEND ARCHITECTURE (C# .NET Core Web API)
--------------------------------------------------------------------------------
- Layers:
  * Repositories (Data Access Layer via EF Core / AppDbContext)
  * Services (Business Logic Layer: PricingService, RoutingService, NotificationService, InvoiceService)
  * Controllers (API Endpoints with JWT Authorization)
- Key Modules:
  * Auth Controller: /api/auth/login, /api/auth/register
  * Client CRM Controller: /api/clients (CRUD operations)
  * Order Controller: /api/orders/quote, /api/orders (creation with dynamic distance calculation)
  * Driver Controller: /api/driver/assigned, /api/driver/orders/{id}/pod (PoD submission and availability release)

--------------------------------------------------------------------------------
5. FRONTEND ARCHITECTURE (Next.js 14+ App Router & TypeScript)
--------------------------------------------------------------------------------
- Views / Routes:
  * /app/(auth)/login/page.tsx -> Universal login screen routing based on JWT role.
  * /app/client-portal/new-order/page.tsx -> B2B booking form with address inputs, special instructions field, and instant quote preview.
  * /app/driver/active-run/page.tsx -> Mobile PWA driver view featuring job details, navigation links, and HTML5 canvas signature pad for digital Proof of Delivery.
  * /app/admin/dashboard/page.tsx -> Operations dashboard for managing orders, manual driver dispatching, and tracking invoice statuses.
